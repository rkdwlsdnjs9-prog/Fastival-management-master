# 프론트엔드 코딩 규칙 (Frontend Coding Standards)

이 프로젝트는 유지보수성과 코드 품질 향상을 위해 구조(HTML), 표현(CSS), 동작(JavaScript)의 완전한 분리를 원칙으로 합니다.
모든 개발자는 프로젝트 시작 전 및 개발 과정 중 아래 규칙을 반드시 숙지하고 준수해야 합니다.

## 1. HTML 내 인라인 스타일 사용 절대 금지
- **어떤 HTML 파일 내부에도 단 하나의 인라인 스타일(`style="..."`)을 허용하지 않습니다.**
- HTML 내부에 `<style>` 태그를 배치하여 내부 코딩을 하는 것 또한 **절대 금지**합니다.
- **해결 방안:** 모든 스타일은 반드시 외부 CSS 파일(`.css`)에 클래스(class)나 아이디(id) 형태로 정의한 뒤, HTML에서 `<link rel="stylesheet" href="...">`를 통해 로드하여 사용하세요.

## 2. HTML 내 인라인 스크립트 사용 절대 금지
- **어떤 HTML 요소에도 인라인 스크립트 이벤트 핸들러(예: `onclick="..."`, `onchange="..."` 등)를 허용하지 않습니다.**
- HTML 내부에 `<script>` 태그를 열어 로직을 작성하는 행위 역시 **절대 금지**합니다. (외부 라이브러리 로드를 위한 `<script src="...">`만 허용)
- **해결 방안:** 모든 자바스크립트 동작은 외부 JS 파일(`.js`)에 작성하며, DOM이 로드된 후 `addEventListener`나 이벤트 위임(Event Delegation) 방식을 사용하여 요소에 이벤트를 바인딩해야 합니다.

## 3. 코드 분리 원칙 (Separation of Concerns)
- **구조 (HTML):** 콘텐츠의 뼈대와 의미망(Semantic) 구축에만 집중합니다.
- **표현 (CSS):** 디자인 요소, 레이아웃, 애니메이션 등 시각적 처리에만 집중합니다.
- **동작 (JavaScript):** 사용자 상호작용, 데이터 통신, 동적 DOM 제어에만 집중합니다.

## 4. Markdown 파일 내 이모지/이모티콘 사용 금지
- **`.md` 확장자를 가진 문서에서 시스템 이모지나 특수문자 이모티콘의 사용을 금지합니다.**
- **해결 방안:** 시각적인 표현이나 아이콘이 필요한 경우 반드시 SVG 포맷의 아이콘 코드를 활용하세요.

위 규칙은 어떠한 예외 없이 모든 코드에 적용되며, 디자인 및 기능 훼손 없이 규칙을 준수하도록 지속적으로 점검해야 합니다.
